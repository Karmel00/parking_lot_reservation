# parking_lot_reservation
Aplikacja webowa i mobilna do rezerwacji miejsc parkingowych: użytkownik znajduje parking, sprawdza wolne miejsca w wybranym czasie, rezerwuje je i dostaje potwierdzenie e-mailem.
System działa w chmurze AWS To projekt.
Funkcje
rejestracja i logowanie (e-mail + hasło)
lista parkingów i wyszukiwanie wolnych miejsc w wybranym przedziale czasu
rezerwacja i anulowanie miejsca, lista moich rezerwacji
potwierdzenia e-mail
prosty panel administratora do zarządzania parkingami i miejscami
